# Screenshot Studio

Free App Store and Google Play screenshot maker. Drop in app screenshots, write a headline, pick a
template and export store-ready images for iPhone, iPhone Duo, iPad, Android phones and Android tablets,
in portrait or landscape.

- 12 starter designs to pick from and a Randomize button that mixes theme, font, layout, colours and
  frame, with one-step undo
- 15 templates: classic, caption block, tilted, isometric, pair, trio, panorama across two slides,
  close-up, full bleed, text only and more
- 47 fonts loaded on demand from Google Fonts, 18 of them with Thai; Thai text wraps at word boundaries
- Highlighted keywords (`*like this*`), label pills, laurel / star / pill rating badges
- Linear, radial, mesh, solid and photo backgrounds, 11 decorations, film grain, 16 one-tap themes,
  per-slide colours
- Realistic, clay and frameless devices; iOS and Android device chrome follows the export target
- Exact App Store Connect and Google Play sizes, PNG without alpha or JPEG, one ZIP with a folder per size
- Works on phones; the project is saved in the browser (IndexedDB) and never uploaded

Everything runs in the browser: no build step, no server. Open `index.html` or host the folder on any
static host such as GitHub Pages. The canonical URL, Open Graph tags and `sitemap.xml` assume
`https://pond1982.github.io/screenshot-studio/`; change them if the site lives elsewhere.
